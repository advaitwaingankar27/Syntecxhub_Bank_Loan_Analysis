# Syntecxhub Bank Loan Analysis

## 📌 Project Overview

This project analyzes **bank loan data** to understand loan applications, funded amounts, repayment performance, borrower characteristics, and overall lending trends.

The analysis uses data visualization and business intelligence techniques to transform raw loan data into meaningful insights that can support better lending and financial decision-making.

## 🎯 Objectives

* Analyze loan application trends
* Understand loan approval and funding patterns
* Analyze borrower characteristics
* Evaluate loan repayment performance
* Identify good and bad loan patterns
* Analyze loan amounts and interest rates
* Create meaningful KPIs and visualizations

## 📊 Key Areas Analyzed

* Total Loan Applications
* Total Funded Amount
* Total Amount Received
* Average Interest Rate
* Average Debt-to-Income Ratio (DTI)
* Loan Status
* Loan Purpose
* Loan Grade
* Employment Length
* Home Ownership
* Loan Term
* Monthly Trends
* Good Loan vs Bad Loan Performance

## 📈 Key Performance Indicators

The analysis focuses on important banking KPIs such as:

* **Total Loan Applications**
* **Total Funded Amount**
* **Total Amount Received**
* **Average Interest Rate**
* **Average DTI**
* **Good Loan Percentage**
* **Bad Loan Percentage**

## 🔍 Key Questions

The analysis helps answer:

1. How many loan applications were received?
2. What is the total amount funded?
3. How much amount has been received from borrowers?
4. What percentage of loans are good and bad?
5. Which loan purposes have the highest demand?
6. Which loan grades have better repayment performance?
7. How does loan performance vary by employment length?
8. How does home ownership affect loan activity?
9. What trends can be observed in loan applications over time?
10. Which factors are associated with loan repayment performance?

## 🛠️ Tools & Technologies

* **Power BI** – Data visualization and dashboard development
* **Power Query** – Data cleaning and transformation
* **DAX** – KPI calculations and measures
* **Excel / CSV** – Data source

## 💼 Business Value

This analysis can help financial institutions:

* Monitor lending performance
* Understand borrower profiles
* Identify high-risk loan segments
* Track loan funding and repayment
* Evaluate loan portfolio performance
* Improve lending strategies
* Support data-driven financial decisions

## 🚀 Conclusion

The **Syntecxhub Bank Loan Analysis** project demonstrates how data analytics and visualization can be used to understand loan portfolio performance.

By analyzing applications, funding, repayment, borrower characteristics, loan grades, and loan purposes, the project provides valuable insights that can support **risk assessment, lending decisions, and overall banking strategy**.
